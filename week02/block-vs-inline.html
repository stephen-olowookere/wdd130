In the HTML of this document, change this div element to a span element.

What happens to these layout? Does it still take up the full width?, No "Changing the div to a span changed the layout: it no longer takes up the full width, it only hugs its content. It doesn't stand on its own by choice; it just ends up alone on a line because the block elements around it (the h2 above and the p below) force line breaks. If there were inline content next to it instead, it would share that line."
